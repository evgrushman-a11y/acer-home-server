Privacy Policy

Last updated: November 16, 2026

Purpose

Acer Home Server is a personal, non-commercial application used by its owner for automated encrypted backups.

Google Drive Access

The application uses Rclone to access the owner's Google Drive account for storing and retrieving backup files.

Data Security

Backup data is encrypted locally using Restic before being uploaded to Google Drive.

Data Sharing

The application is not available to external users. Backup data is not sold or shared with third parties by the application owner.

Data Retention

Backup files are retained according to the owner's backup policy and may be deleted by the owner.

Revoking Access

The owner can revoke the application's Google Drive access through Google Account security settings.
